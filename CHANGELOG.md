# Changelog

All notable changes to the UTM Link Generator extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release of UTM Link Generator Chrome extension
- Core UTM link generation with source, medium, campaign, term, and content parameters
- Real-time form validation with inline error messages
- Reusable template system with pattern support (date, month, year variables)
- Auto-fill functionality using page context and smart heuristics
- Link history with search capability (50 entries for free users)
- Auto-copy to clipboard for generated URLs
- Content script integration with quick access overlay
- Professional popup interface with modern design
- Comprehensive options page for settings and template management
- Premium feature gating with freemium model
- License activation system for Pro subscriptions
- Google Sheets integration (Premium)
- Bulk generation and CSV export (Premium)
- Team collaboration features (Premium)
- Responsive design with dark mode support
- Extensive error handling and user feedback
- Data migration system for future updates
- Comprehensive documentation and development guides

### Technical Features
- Manifest V3 compliance for modern Chrome extensions
- Service worker architecture for background processing
- Chrome Storage API integration with sync and local storage
- Defensive coding practices with comprehensive error handling
- Modular architecture with clear separation of concerns
- Performance optimizations and memory management
- Security best practices with minimal permissions
- Cross-browser compatibility (Chrome, Edge, Brave)

### Free Tier Features
- Basic UTM generation
- Up to 5 templates
- 50 history entries
- Manual copy/paste workflow
- Real-time validation
- Auto-fill from page context

### Premium Features
- Unlimited templates
- Bulk generation with CSV export
- Google Sheets integration
- Unlimited history
- Advanced template patterns
- Team sharing and collaboration
- Priority support

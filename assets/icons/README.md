# UTM Link Generator Icons

This directory should contain the following icon files:

## Required Icons

- `icon-16.png` - 16x16 pixels - Used in browser toolbar
- `icon-48.png` - 48x48 pixels - Used in extension management page
- `icon-128.png` - 128x128 pixels - Used in Chrome Web Store

## Icon Specifications

- **Format**: PNG with transparent background
- **Style**: Modern, clean design with the UTM Link Generator brand
- **Colors**: Primary blue (#2563EB) with white accents
- **Content**: Should clearly represent link/URL generation functionality

## Design Guidelines

- Use consistent visual style across all sizes
- Ensure good visibility at small sizes (16px)
- Maintain brand consistency with the extension UI
- Consider both light and dark browser themes

## Creating Icons

You can create these icons using:
- Adobe Illustrator/Photoshop
- Figma
- Sketch
- Online icon generators
- SVG to PNG converters
